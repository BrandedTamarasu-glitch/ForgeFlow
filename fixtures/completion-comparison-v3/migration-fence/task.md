Both contain plain dictionaries with string values indexed by arbitrary string keys, including names inherited from Object.prototype. Backend reads provide a revision; writes require the expected revision and reject stale writes. Unsupported versions and malformed entry documents must fail loading and must not subsequently permit writes. A failed reload invalidates the previous loaded state. Backend write failures must leave the store retryable. Snapshots must be detached copies. Concurrent stores must preserve successful writes.
