# Native release fixture

Authored synthetic C application under the repository MIT license. No production code, package, credentials or user profile is copied. `application.c` builds into two native Linux ELF executables using `cc`. Version 1 reads/writes schema 1; version 2 migrates schema 1 to schema 2 while retaining a launch counter. Version 1 rejects newer data before writing. This is a serial lifecycle fixture, not a production persistence implementation or crash/durability test.

Run `npm run test:native-release` on Linux with `/proc` and `cc` already available. Missing platform/compiler exits 2 with an explicit unverified result. No dependencies are downloaded. Every subprocess has a ten-second timeout and runs in an unrelated working directory. Installed binaries report their executing path from `/proc/self/exe`; the harness independently checks installed hashes against the pre-install build manifest and the ELF signature. The compiler uses C11 with warnings treated as errors.

Checks cover first run, restart in a separate process, stale installed bytes despite a successful newer build, update/migration, updated restart, incompatible binary-only rollback with preserved data, explicit snapshot recovery, malformed-profile rejection, non-executable permissions, uninstall with retained user data and untouched unrelated files/profile, and reinstall using retained state. Snapshot recovery deliberately discards two post-update counter increments; it is not lossless downgrade. The installed executable is copied and replaced by the harness, so installer/update/uninstall orchestration is simulated even though the compiled program, filesystem and child process launches are real on the host.

The JSON report separates build, installed, actual-host, simulated installer, human, desktop UI and platform evidence. It includes source/artifact hashes, commands, exit codes, process outputs and kernel/compiler identity. Work directories, installed binaries and disposable profiles are removed in `finally`; cleanup failure fails the suite. The small evidence directory is deliberately retained under the printed temporary path for local review. It contains local paths and must not be committed or published as-is.

Limits: Linux CLI fixture only. No graphical application, keyboard/focus or screen-reader qualification; no real OS package manager, application signing, launch service, background process, live production installation or public release. Windows/macOS remain unverified. No power-loss durability, concurrent update or model-benefit claim. Before a later model pilot, independently challenge and freeze the controls and oracle; these engineering checks are not independent agent trials.
