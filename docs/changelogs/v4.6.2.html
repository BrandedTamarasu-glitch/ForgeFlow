ForgeFlow V4.6.2 · 11 September 2026

Complete local shipping previews

Shipping previews previously listed only committed branch changes. This patch includes staged and unstaged edits and nonignored new files, so you can inspect the local change before committing.

Changes

  • Compare both the index and working tree with the branch merge base, and add nonignored untracked paths.
  • List each path once and derive the preview count from that same inventory. Preserve staged changes even when an unstaged edit restores the base content.
  • Parse NUL-delimited Git output to preserve filenames containing tabs or newlines. Show renames as a deletion and an addition.
  • Keep task evidence, freshness checks, and reviewer approval separate from file inclusion.

Validation and limits

Regression coverage exercises committed changes, staged and unstaged edits, deletions, renames, untracked and ignored files, unusual filenames, repeated previews, and both installed host layouts. The release announcement records the final local check results. The inventory does not stage or commit files and does not select which files belong in a release.

Updating

Existing 4.6.x installations can use the current updater. For the first upgrade from legacy agent names, follow the source-checkout migration procedure. GitHub Actions remains disabled.
